Duotone prints

            
Any photo, graded into one of the palette's colours by CSS alone. It regrades when the palette or mode changes, and develops out of blank paper as it scrolls in.

            
<figure class="wal-duotone wal-reveal-develop" data-ink="cool">
  <img src="photo.jpg" alt="…">
</figure>

            
walnut.css, no script. data-ink picks accent, bloom, gold, olive or cool. Forced colours show the photo as it is.

Recolour from the button

            
A new palette opens out of the button that chose it. Every frame is all old or all new, so text stays readable throughout.

            
<script src="walnut-recolour.js" defer></script>
<html class="wal-forest" data-wal-recolour="swatch">
<button data-wal-palette="wal-dusk">Dusk</button>

            
walnut-recolour.js, optional. It keeps aria-pressed in step, and aria-controls aims a button at one section. Reduced motion swaps at once.

          

          

            
Drawers

            
Each drawer is a <details>. One name makes them a chest, so pulling one out pushes the last one home. In walnut, a drawer runs out heavy and knocks on its stop.

            
<div class="wal-chest" data-wal-material="walnut">
  <details name="colourway">
    <summary>Forest</summary>
    <div>…</div>
  </details>
</div>

            
walnut.css, no script. Keyboard and find-in-page work as they do on any details.

How a photo becomes a palette

            
    
              
  1. The photo is read at 72 pixels across, each pixel as an oklch colour.
    2. 
              
  2. Pixels are grouped by hue, 10° to a group. Greys and extremes give the ground its faint cast.
    3. 
              
  3. Five groups become the colours: the strongest first, each at least 28° from any already taken, so a sunset does not give five oranges. The strongest leads as the accent; the rest take roles by where they sit on the wheel.
    4. 
              
  4. Each colour is fitted inside sRGB and every text pair is measured. One that fails is pulled back, or its lightness moves the least that passes.
    5. 
            

            
Nothing to install. Paste the CSS after walnut.css. Your photo is read in this tab and never uploaded.

          

        

      

    


    

      

        

          
Install

          
One stylesheet, 17 KB gzipped. No build step, no runtime. Everything else is optional.

        

        

          
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SKMinWoo/walnut.css@v0.4.0/dist/walnut.min.css">

          
        

        

          

            
AddFor

            
              
themes/forest.cssA shipped palette: Forest, Bone, Café, Dusk or Press. One class on a page or a section.

              
walnut-recolour.jsPalette buttons that recolour the page from the button pressed.

              
walnut-motion.jsDoors you drag shut by the pull, windows that open as a gatefold, and lists that shuffle.

              
walnut-acts.jsA page that changes palette section by section as you scroll.

              
walnut-scroll.cssCarousel dots and a nav that lights the section in view, with no script. Chrome and Edge.
