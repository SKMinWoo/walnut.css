Philosophy

Modern, Cinematic CSS

Built with cutting-edge CSS features and an eye for pacing.

Color

oklch System

Vibrant, perceptually uniform colors that gracefully degrade for older browsers.

Architecture

@layer Cascade

Avoid specificity wars. Everything is neatly organized into reset, base, components, and utilities layers.

Responsive

Container Queries

Components adapt to their containers, not just the viewport. Build truly modular interfaces.

Motion

Scroll Animations

Cinematic, scroll-driven reveals that respect prefers-reduced-motion preferences.

Design

4 Curated Themes

Café, Botanical, Midnight, and Snow. Switch with a single class change on the root.

Clean

Zero JS

Interactions powered by modern CSS features like :has(), popover, and anchor positioning.
